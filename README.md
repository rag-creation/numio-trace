# Trace by Numio

**Remember when you last did the little things.**

When did I last change the AC filter? Wash the bedsheets? Give the laptop for repair?
Trace is a tiny offline log for small everyday jobs. Type it in a few seconds, and later
Trace tells you when you last did it, how often you usually do it, and roughly when it's due again.

No internet permission, no ads, no tracking, no account. Your traces never leave your phone.

> Work in progress. Not released yet.

## Features

- **Quick add**: tap +, type what you did, save. Things you've logged before show up as you type, so logging again is one tap.
- **Timeline**: everything you've traced, grouped by day.
- **Search**: "When did I last…" finds a thing by name, tag or note.
- **History of one thing**: every time you did it, the gap between each time, how often you usually do it, and a rough next date.
- **Did it again**: one button to log it for today, with undo.
- **Edit or delete** any trace: tap it in a thing's history, or long-press it on the timeline.
- **Coming round again**: things you do regularly, sorted by when they're due next.
- **Now, yesterday or any past day**, plus an optional note and tag.
- **Light, dark or follow system** theme.

## Privacy

Trace asks for **no permissions at all**. It has no internet permission, so it can't send anything anywhere.
Everything is stored in the app's private storage. Saving writes a new copy first and swaps it in,
so a crash or a dead battery never leaves you with half-saved data.
Every build is checked to make sure the internet permission never sneaks in.
